# Trial contract

## Scope

Implement and exercise the repo-wide derived index tools. Do not add a daily
job, GitHub Action, workflow hook, RAG store, graph store, or new canonical
policy.

## Acceptance targets

These are design targets for this trial, to be measured rather than assumed:

- strict no-op `--check` p95 ≤ 0.75 s (the original 0.5 s aspiration was
  recalibrated during review because this mode deliberately hashes every source
  to catch metadata-preserving external edits);
- one-file edit/update p95 ≤ 1 s;
- move/delete update p95 ≤ 2 s;
- lexical query p95 ≤ 1 s;
- full rebuild of the current repository ≤ 10 s;
- deterministic generated bytes for the same tree/config/baseline argument;
- zero false canonical authority assignments;
- all indexed paths remain within the repository and all schema/link checks pass.

## Required lifecycle cases

Initial build, no-op, edit, exact move, move-plus-edit, create, delete, copy,
duplicate content, case-only rename on Windows, unstable read retry/failure,
generated/cache exclusion, authority search filtering, and stale package
verification must be exercised before integration.

## Decision gate

This run ends in `Awaiting decision` after independent review. Only the owner
may authorize integration into `main`.
